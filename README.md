## Sobre mim

Sou desenvolvedor de software no Porto — **backend, mobile e integração de sistemas**.
Neste momento trabalho na **WorkInNet** no ecossistema **InspGest** (inspeção automóvel), com C#, VB.NET, Kotlin e SQL. Também publico apps Android na Play Store.

## Stacks núcleo

| Stack | Uso |
|---|---|
| **C# / .NET** (+ VB.NET) | Backend, desktop e integrações InspGest |
| **Kotlin / Android** | Apps Play Store e clientes móveis |
| **SQL Server** | Dados e migrações em software de negócio |
| **Node.js** | APIs e integração de sistemas |

Também usei (secundário): JavaScript/TypeScript, PHP/Laravel, Java, MySQL/MongoDB, Python, WordPress, Blazor/React, Xamarin/MAUI.
